# mild-shaper-mini

Edge Computing · Distributed Systems · Machine Learning

处理日常小任务的工具

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```
